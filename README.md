# Construction Progress Monitoring

AI-powered system that compares planned construction (BIM models) against actual built reality (drone photogrammetry, site photos, and point clouds). Two frontend variants — an analytics dashboard and a 3D digital twin — will consume the same shared schema and data.

Schema definition lives in [`shared/schema/README.md`](shared/schema/README.md). **Phase 2** (data generation) and **Phase 3** (PRDs) are not yet started.
